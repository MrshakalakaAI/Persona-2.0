## Реальные функции

- Фото: импорт, системная камера спереди/сзади, поворот, выравнивание, пропорции, масштаб и сдвиг crop, до/после, история 60 шагов, JPEG-экспорт до 4096 px без водяных знаков и переноса GPS.
- Семь собственных образов и состояние «Без образа», общая интенсивность, дополнительные ручные настройки.
- 43 портретных регулятора: кожа/текстура/краснота/тон/сияние/лоб/подглазья; ширина/высота лица, челюсть, подбородок, скулы, лоб и брови; размеры/расстояние/подъём глаз, приблизительная радужка, свет/контраст/насыщенность; нос/переносица/кончик; губы/улыбка/зубы; макияж.
- Точечные кисти: соседняя текстура, сглаживание, осветление, затемнение; до 80 точек, undo по жесту; координаты учитывают crop/rotation.
- Выбор отдельного лица из нескольких, порядок слева направо.
- Восемь фотофильтров, свет/цвет, общее шумоподавление, резкость, света/тени, виньетка.
- Видео: импорт, AVPlayer, цвет/фильтры/crop/9:16, MP4 с исходным звуком; опциональная покадровая ретушь лица до 1280 px и отмена экспорта.
- Русский графитовый интерфейс, выбор портретного инструмента с одним активным регулятором; встроенный публичный пример NASA/scikit-image.

## Проверки

**21 unit/integration + 1 UI test = 22/22 PASS.**

Unit tests подтверждают: реальное обнаружение лица и landmarks на публичном портрете, рендер всех образов и всех детальных инструментов, исключение невыбранного лица, healing изолированного дефекта, обратное преобразование координат кисти при всех ориентациях, видеоанализ реального портрета, нейтральную обработку, фильтры, экспозицию, crop, историю/сериализацию, ориентацию/размер импорта, невалидный файл, координаты масок, локальную геометрию, JPEG и MP4 9:16 с аудио. Видеоэкспорт проверен на синтетическом аудиовидеофайле с включённым покадровым анализом; движущееся реальное лицо на iPhone не тестировалось.

UI test загружает настоящий тестовый портрет, выбирает образ, проверяет undo/redo, справку и наличие сохранения. Время unit suites в данном CI — 59.3 s, UI test — 37.6 s; это **не** FPS или benchmark iPhone.

После скачивания независимо проверены: SHA-256, целостность ZIP, один app, ARM64 Mach-O, версия, Bundle ID `com.personafree.editor`, имя `personaж`, minimum iOS `17.0`, разрешения камеры/Фото, отсутствие подписи, тестовых бандлов и извлечённых моделей Persona. PNG интерфейса и PNG обработанного портрета просмотрены: лицо найдено, изображение и нижняя панель видны, явных разрывов на тестовом портрете не обнаружено. Это не доказательство качества на любых лицах.

## Ограничения

- Нет идентичных 239 моделей/масок Persona, генеративного омоложения, изменения волос/тела, нейронного восстановления дефектов. Подробности — PERSONA_AUDIT.md.
- Маска кожи приближённая: геометрия Vision + цветовой фильтр, без обученной сегментации. Профиль, волосы, очки и перекрытия могут давать артефакты; фон около лица иногда деформируется.
- Кисть переносит соседнюю текстуру, без семантического восстановления. Глубокие дефекты/морщины не восстанавливаются.
- Образы добавляют собственные параметры к ручным. «Нюд» и «Вечер» фиксируют оттенок; для свободной палитры нужно выключить образ.
- Покадровое видео может быть медленным и иметь дрожание точек; нет отдельного temporal tracker, live beauty preview и записи видео камерой внутри приложения. HDR может перейти в SDR.
- Фото — до 4096 px; при ретуши видео — до 1280 px. Много кистевых точек увеличивает время обработки. Промежуточные checkpoints используют sRGB RGBA8; аппаратная скорость не подтверждена.
- Нет долговременных проектов и сохранения истории между запусками.
- Настоящие камера, Photos/iCloud/отказы разрешений, подпись Lazy, память, температура и скорость на физическом iPhone не проверены. Runtime iOS 17 отдельно не запускался; deployment target 17 проверен компилятором.
- Core Image Kernel Language API устаревший, но доступный для deployment target. Совместимость Swift 6 не заявляется; проект использует Swift 5.9.

## Почему не работает «Красота» в присланном IPA

Точный диагноз не установлен: IPA не запускался на iPhone, журнала ошибки нет. В нём 239 каталогов Core ML, 238 с encryptionInfo, а также сторонние внедрённые библиотеки. Только у 10 каталогов есть файлы с weight в имени, но это не доказывает отсутствие весов в остальных представлениях. Наличие интерфейса и каталога модели не гарантирует успешную загрузку. Ошибка ключей/данных модели или вмешательство модификаций — гипотезы. Apple описывает отдельное получение ключа при первой загрузке зашифрованной модели; получения или обхода этих ключей в этой работе не было.

## Подпись и установка

Скачать IPA → импортировать в подписыватель Lazy → выбрать свой действующий сертификат и совместимый provisioning profile → подписать → установить. При ограниченном профиле нужен разрешённый Bundle ID. Названия пунктов зависят от версии Lazy. Unsigned IPA напрямую не устанавливается; сертификат и пароль не добавлять в GitHub.

## Бесплатность и дальнейшая работа

Нет платных API, подписок, облачных GPU или runtime SDK аналитики. Обработка на устройстве. Стандартный Intel macOS runner публичного репозитория; платное Actions artifact storage не используется. Код MIT, графика оригинальная, тестовый портрет public domain с источником в Resources/DEMO_LICENSE.txt.

Готовность относительно полноценной замены Persona: **6/10**. Сборка и базовые сценарии подтверждены; полноценные нейронные маски и аппаратное качество остаются существенным разрывом. Для дальнейшего развития нужны отдельно проверенные по лицензии модели, проверка сохранения идентичности, стабильность видео и испытания на iPhone. Исследованные открытые варианты описаны в PERSONA_AUDIT.md; они не объявляются готовыми заменами Persona.
