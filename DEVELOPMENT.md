# Журнал разработки

## 2026-11-12: аудит и реализация

Исходная точка: `bc9b172`, один SwiftUI-файл с шестью общими регулировками, без Vision, камеры и видео. Прямой GitHub API обнаружил 4 запуска в состоянии queued, включая `43195563513`; успешной сборки исходного коммита на момент аудита не было. Connector fetch_commit_workflow_runs вернул пустой список, поэтому использован прямой API.

Локальная среда Linux не содержит Swift/Xcode. Компиляция и XCTest должны выполняться в macOS Actions; локальная проверка не выдаётся за iOS-сборку.

Выполнено: разделение архитектуры; добавлены Vision/masks/retouch/makeup/warps/crop; фото и видео I/O; история; русский интерфейс; иконка; privacy manifest; 13 XCTest-проверок включая реальный AVFoundation MP4-экспорт синтетической аудиовидеозаписи; валидатор IPA; Release workflow без платного artifact-хранилища.

Прямой запрос check-run annotations подтвердил причину старых сбоев: `The job was not acquired by Runner of type hosted even after multiple attempts`; GitHub также указал ограничения ёмкости macOS arm64. Runner заменён на стандартный бесплатный `macos-15-intel`, без увеличения размера машины.
