Прямой GitHub API обнаружил 4 запуска в состоянии queued, включая `43195563513`; успешной сборки исходного коммита на момент аудита не было. ### Инфраструктура Actions

Прямой запрос check-run annotations подтвердил причину старых сбоев: `The job was not acquired by Runner of type hosted even after multiple attempts`; GitHub также указал ограничения ёмкости macOS arm64. Runner заменён на стандартный бесплатный `macos-15-intel`, без увеличения размера машины.

### Первая компиляция

Intel runner успешно выделен. Запуск `43198093289` дошёл до компилятора и обнаружил два исправляемых дефекта: отсутствующий CoreImage import в VideoEngine и async seek без await в EditorModel. Исправлены; тесты до этого этапа ещё не запускались.

### Дополнительные проверки и улучшения

Добавлены UI smoke test с детерминированным локальным изображением в Debug (фильтр, undo/redo, справка), проверка реального перемещения пикселей геометрией, независимая маска смягчения лба и освобождение загруженного фото при переходе к видео. Сетевые API и платные SDK в Sources отсутствуют. Лицензии XcodeGen, actions/checkout и GitHub CLI проверены по LICENSE их репозиториев: MIT.
