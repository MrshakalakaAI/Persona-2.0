# Beauty Studio (Persona Free prototype)

Open-source iOS photo editor. No paid APIs or subscriptions.

## Current functionality
Photo picker, live image adjustments (brightness, contrast, saturation, warmth, noise reduction, sharpness), reset and photo export.

This is an early prototype, **not** a full-featured beauty retouch application. Face-aware retouch, makeup, geometry adjustments, video editing and camera capture are not implemented.

## Build
GitHub Actions > Build unsigned IPA. The resulting unsigned IPA requires signing with a personal certificate before installation.

## Technology
SwiftUI, PhotosUI, Core Image, XcodeGen. iOS 17+.
