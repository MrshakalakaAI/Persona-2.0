# personaж 1.3 — разработка

Независимый локальный редактор фото и видео, iOS 17+. Не полная копия нейронных масок Persona. Bundle ID `com.personafree.editor`.

## Статус сборки

Последняя полностью проверенная сборка — [1.2.0 (12), build-17](https://github.com/MrshakalakaAI/Persona-2.0/releases/tag/build-17), 26/26 tests. Изменения 1.3 находятся в main, но **пока не подтверждены сборкой и тестами**: [run 43247160036](https://github.com/MrshakalakaAI/Persona-2.0/actions/runs/43247160036) ожидает стандартный macOS runner. Отчёт RELEASE_REPORT.md относится к проверенной 1.2. Новая IPA публикуется только после успешного CI.

## Фильтры и образы 1.3

12 независимых портретных образов плюс «Без образа», 12 цветовых рецептов плюс оригинал. Миниатюры вычисляются на исходном фото, для каждого рецепта при 100%; большой предпросмотр учитывает все текущие правки. Цветовые рецепты общие с видео. Различимость, направление тёплого/холодного/монохрома, сила и публикация preview проверяются новыми тестами; результат этого прогона пока не получен.

[Исследование официальных возможностей Persona и пределы реализации](FILTER_RESEARCH.md).

## Исправления «Красоты» в 1.2

- Сглаживание использует низкочастотную основу с контролируемым возвратом текстуры внутри маски кожи. Усилены рецепты образов и локальные эффекты.
- Оболочка лица строится независимо от порядка точек Vision; глаза, рот и брови исключаются из кожи.
- Интенсивность по умолчанию 100%; выбор образа доступен в меню рядом с регулятором. После рендера показано подтверждение применённого образа.
- Сравнение автоматически сбрасывается при отмене жеста; ручной оттенок макияжа применяется и в «Нюд»/«Вечер».
- Добавлены проверки изменения пикселей лица и губ, нулевой/частичной/полной силы и публикации нового предпросмотра.

## Что добавлено после анализа предоставленного IPA

- Тринадцать состояний образа (включая «Без образа») с одной общей силой; собственные сочетания ретуши, макияжа и геометрии.
- Разделение частот для сглаживания с возвратом текстуры, ограничение маски кожи по геометрии и цвету, ровный тон и сияние.
- Свет, контраст и насыщенность глаз, отбеливание светлых пикселей зубов внутри открытого рта.
- Подробная геометрия: размеры/расстояние/подъём глаз, радужка; нос/переносица/кончик; губы/улыбка; челюсть/лоб/высота лица; брови.
- Выбор отдельного лица в группе, сортировка слева направо.
- Точечные кисти: перенос соседней текстуры, сглаживание, осветление и затемнение. Мягкие края, до 80 точек, undo по жесту. Координаты учитывают crop/rotation.
- Вместо длинного списка всех регуляторов — выбор инструмента и один активный слайдер для портретных категорий.
- Опциональная покадровая ретушь видео: Vision + тот же локальный конвейер, до 1280 px по длинной стороне, с исходным звуком. Можно отменить экспорт.
- Публичный портрет NASA/scikit-image для примера и настоящих Vision-тестов.

Аудит и ограничения: [PERSONA_AUDIT.md](PERSONA_AUDIT.md).

## Реализовано в исходном коде

- PhotosPicker: фото и видео; камера iPhone с переключением передней/задней камеры, пересъёмкой и просмотром через системный интерфейс.
- Vision: обнаружение нескольких лиц, контуры глаз, носа, губ, челюсти и бровей.
- Кожа: локальное шумоподавление, медианное подавление мелких неровностей, уменьшение красноты, оттенок кожи, свет под глазами, смягчение морщин. Глаза, губы и брови исключаются из маски кожи.
- Геометрия: ширина лица/носа, подбородок, скулы, размер глаз/губ и изгиб бровей. Компактные плавные деформации с ограниченной амплитудой.
- Макияж по точкам лица: помада с исключением внутреннего рта, румяна, тени, верхняя подводка, брови; пять оттенков, отдельная интенсивность.
- Двенадцать цветовых рецептов, оригинал и сила фильтра; экспозиция, яркость, контраст, насыщенность, температура, резкость, общее шумоподавление, света, тени, виньетка.
- Поворот, выравнивание ±15°, пропорции, масштаб и сдвиг области кадра; до/после, отмена/повтор до 60 шагов, сброс с отменой.
- Фото: экспорт JPEG sRGB до 4096 px по длинной стороне, без водяных знаков и копирования исходных GPS-метаданных.
- Видео: просмотр AVPlayer, цвет/фильтры, поворот/кадрирование, 9:16, экспорт MP4 с исходной аудиодорожкой; опциональная покадровая ретушь. Временные копии удаляются при смене видео и после экспорта.
- Оригинальный русский интерфейс: графит, розово-лиловые акценты, адаптивный предпросмотр, нижние категории, VoiceOver-подписи.

Наличие кода не заменяет проверку сборки. Статус конкретного коммита смотри в Actions и `DEVELOPMENT.md`.

## Ограничения качества

Это не эквивалент коммерческой нейросетевой ретуши Persona. Маски основаны на геометрии Vision, без обученной модели сегментации кожи: волосы, борода, очки, профиль и перекрывающиеся лица могут давать ошибки. Мелкие неровности сглаживаются медианным фильтром, без семантического распознавания прыщей. Глубокие дефекты, отсутствующая текстура и глубокие морщины не восстанавливаются. Формы глаз/лица изменяются умеренно; фон около контура иногда деформируется. По умолчанию эффекты применяются ко всем найденным лицам; можно выбрать одно.

Ретушь лица, геометрия и макияж в видео включаются отдельно в разделе «Видео». Это покадровая обработка без гарантии real-time; возможны дрожание landmarks и медленный экспорт, предел 1280 px. Live beauty preview камеры отсутствует: камера снимает исходник, обработка выполняется после съёмки. HDR-видео может перейти в SDR. Фото ограничены 4096 px для контроля памяти; RAW/depth/Live Photo редактируются как обычное неподвижное изображение при доступном декодировании. История не сохраняется после закрытия приложения. На настоящем iPhone приложение пока не проверено.

## Архитектура

- `Sources/Models`: настройки, история, главный актор UI, последовательный фоновый photo worker.
- `Sources/Processing`: Vision, маски, Core Image, Metal-backed CIContext, локальный warp kernel.
- `Sources/Services`: импорт/декодирование, Photos-экспорт, камера, AVFoundation-видео.
- `Sources/UI`: редактор и честно обозначенные ограничения.

Превью ограничено 1280 px; маски растеризуются до 1024 px и масштабируются GPU. Слайдеры объединяют жест в один шаг истории, обработка откладывается на 100 ms и отменяет устаревший результат. Экспорт повторно декодирует исходник с отдельным лимитом. Core Image kernels и фильтры используют GPU при наличии Metal, без сетевых запросов.

## Сборка и проверки

`xcodegen generate`, затем схема `PersonaFree`. `project.yml` — источник проекта.
Workflow `.github/workflows/ipa.yml`: стандартный `macos-15-intel` в публичном репозитории, сборка устройства без подписи, XCTest на симуляторе, проверка структуры IPA и публикация GitHub Release только после успеха. Платные larger runners, облачные API, кэши и Actions artifacts не используются. Логи, контрольная сумма и снимок симулятора прикладываются к Release. UI smoke test загружает локальное тестовое изображение, выбирает фильтр, проверяет undo/redo и справку. Полный xcresult прикладывается к Release. Автоматический тест экспорта создаёт локально видео и PCM-звук, затем проверяет аудиодорожку, длительность и 9:16 после MP4-экспорта.

## Подпись через Lazy

Скачай `personazh-unsigned.ipa` из проверенного Release. Импортируй IPA в используемый тобой подписыватель Lazy, выбери свой действующий сертификат и соответствующий provisioning profile, подпиши и установи. Названия пунктов зависят от версии подписывателя. Если профиль не допускает `com.personafree.editor`, настрой совместимый Bundle ID в подписывателе. Сам по себе unsigned IPA напрямую не устанавливается. Сертификаты и пароли в репозиторий не добавляются.
